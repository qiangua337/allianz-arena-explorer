# 好友联机对战 · 6.1

1. 打开网站的「比赛日选项」，房主选择对手，再点击「和朋友联机 → 创建联机房间」。
2. 把「复制邀请链接」得到的链接发给朋友，或让对方在同一网站输入 8 位房间码。邀请链接会预填房间码，朋友点击加入即可。
3. 双方点击「准备并进入球场」。模型加载完成后自动倒数开球；房主控制拜仁，朋友控制选定客队，其余球员由 AI 配合。

电脑和手机可以混合进入，无需同一 Wi-Fi，无需安装或注册。现有移动、传球、直塞、蓄力射门、抢断、逼抢、换人与镜头操作继续使用。各自独立设置半自动 / 手动 / 辅助换人和射门方式，开球前与暂停时的选择均会保存到当前房间。比分、计时、球、22 名球员与比赛事件共享。联机 AI 使用标准强度。

## 暂停、重连与退出

- 一方点击暂停时两端停止，双方都取消自己的暂停后继续。操作说明也会暂停，避免阅读时继续比赛。
- 暂时掉线会停止比赛，并自动尝试恢复原席位。方向输入超过 500 毫秒没有更新会归零，防止断线后一直跑。切后台停止本机方向输入，服务器继续保持比赛；连接确实中断时才冻结。
- 原席位保留 60 秒重连时间；同一页面刷新后，可用邀请链接 / 原房间码恢复当前标签页保存的身份，再准备进入。完全关闭标签页后，临时身份可能随 sessionStorage 清除。
- 一个房间最多两位玩家。第三人会看到已满提示；同一席位在另一个页面连接会替换旧连接，旧页面不会互相反复抢占席位。
- 退出会结束该房间。房间最长保留 30 分钟，到期后重新创建。全场结束后，双方都点击「再来一场」才重开。

当前是双人对战，尚无同队合作、多人共同参观、聊天、随机匹配或联机回放。网络往返延迟影响手感，计分规则仍采用原有的简化体验赛规则。

## 延迟与手机流畅度

顶部的毫秒数是实际网络往返时间，帧数是当前渲染速度，两者分开显示。6.1 在本机即时预测自己控制球员的移动和带球，服务器确认输入序号后重放尚未确认的方向并平滑校准。球权、自由球轨迹、抢断、得分与比赛时钟仍由服务器决定；暂停、换人、球权变化或连接中断时清除旧预测。连续 600 毫秒没有新状态时停止继续预测，避免跑出真实位置。传射与抢断的本机动作提示不直接改变比赛结果。

手机修复固定帧预算的时间丢失，均衡画质减少抗锯齿多重采样，远处球员降低骨骼姿态频率但每帧仍更新位置。操作说明的「切换到流畅画质」可进一步降低细节，点击「恢复均衡画质」恢复。

新房间使用 Cloudflare 的 `apac` 位置提示；已有房间不会因此自动迁移。该提示为尽力放置，并不保证具体地区或大陆网络低延迟，见 [Cloudflare 数据位置说明](https://developers.cloudflare.com/durable-objects/reference/data-location/)。新版本需要双方刷新网页并新建房间。测试端的延迟数字不能代替玩家手机的实际结果。

## 实现

Pages 继续提供 `dist/` 场景资源。仅 `/api/online/*` 进入 Pages Function，经私有服务绑定访问 `allianz-arena-multiplayer` Worker；每个房间使用一个 SQLite-backed Durable Object。

服务器复用相同的足球模拟，以固定 60 Hz 子步计算，约每 50 毫秒向双方广播压缩的位置数组与比赛状态。客户端只提交带序号的方向和动作，不提交得分、球位置或游戏时间；快照带已实际模拟的输入确认号。远端画面按抖动插值，本机按同一套运动公式预测并校准。网络只保留最近 4 条动作提示，累计比分、事件计数与统计不变；数字按毫米级精度打包，每个快照统一复制后应用。两队各有独立控制者、辅助模式、接球选择与动作队列。暂停、重连和周期检查点可恢复服务器状态。

房间码和邀请链接不包含席位令牌。席位令牌保存在当前标签页的 sessionStorage，通过 WebSocket 握手的子协议字段提交，不放在 URL 中。服务验证同源请求、席位身份、消息大小、频率和输入范围。等待房间不用持续游戏计时器，关闭 / 过期后清理状态。

参考：[Cloudflare WebSocket 与 Durable Objects](https://developers.cloudflare.com/durable-objects/best-practices/websockets/)、[Pages 服务绑定](https://developers.cloudflare.com/pages/functions/bindings/)、[Durable Objects 配额](https://developers.cloudflare.com/durable-objects/platform/pricing/)。现有免费配额可用于小规模好友测试；不修改账号套餐，达到平台限额时服务会受限。

## 本地验证

```sh
npm run check
npm run dev:online
# 另一个终端：
npm run test:online
```

`npm start` 是纯静态预览，适合参观和人机赛，不启动联机后端。

自动化覆盖双队控制、主客队动作、检查点恢复、快照一致性、输入验证、客户端断线冻结与重连身份。`audit-online.mjs` 通过真实 HTTP 和两条 WebSocket 检查创建 / 加入、满员、准备、独立移动、完全一致的服务器状态、共享暂停、开球前及暂停时修改个人操作设置、断线重连和退出清理。实际浏览器另验证两端创建 / 加入与客队移动、传球及暂停。

6.1 增加 300 毫秒条件下首帧响应、输入确认校准、暂停与恢复、动作反馈不改变得分、连接停滞时的预测上限，以及不规则 59 / 60 / 120 Hz 屏幕的 30 帧预算测试。真实连接审计另检查输入序号确认及旧输入不能覆盖新输入。`node scripts/measure-online.mjs URL [OUTPUT_JSON]` 在临时房间内测量 RTT、中位值、P90、快照频率和下载量，结束自动退出；该结果仅代表运行脚本的网络与设备。
