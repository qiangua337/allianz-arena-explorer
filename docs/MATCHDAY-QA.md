# 1.8 比赛日体验验证

2026-10-23 的本地验证记录。测试在开发机浏览器及尺寸模拟中执行，未覆盖所有实体手机 GPU、浏览器和音频输出设备。

| 范围 | 已验证内容 |
| --- | --- |
| 入场流程 | 点击后播放声音；倒计时、通道、台阶、草坪、暂停、继续、跳过、重播、退出 |
| 声音 | 本地 MP3 解码为 39.99 秒；实际分析器返回非零信号；音量归零及恢复可用；暂停后信号为零 |
| 退出 | 恢复原白天 / 黑夜、第一 / 第三人称、相机位置、地图、屋顶、HUD 与导航选择状态 |
| 队友 | 六人沿自己的路线行走，进入草坪后分散；访客侧移不会拖动队友；人物抵达站位后停下 |
| 人物网格 | 正面、背面、侧面检查；头发与衣服贴合人体锚点；领口与腰部无原先的大洞；鞋前后封口朝向正确 |
| 手机尺寸 | 390×844、320×740、844×390；按钮无横向溢出；横屏说明使用左右布局 |
| 手机操作 | 真实指针按住摇杆移动，释放停止；在画面拖动转头；可手动跟随队伍入场 |
| 绘制负担 | 观众使用分区实例化与 GPU 小幅动画；六人共享网格和大部分贴图；入场时才加载人物及声音；手机尺寸下约 53,412 个观众实例 |

自动检查覆盖完整原有步行导航与建筑回归，同时新增入场地面和碰撞、人物独立路线、平地实际蒙皮落脚、权重与资源完整性、衣物重叠、鞋封口、音频启动 / 重试 / 暂停 / 退出期间的异步加载等测试。执行命令为 `npm run check`。

人物仍为通用面部，短发和动作是近似表达。看台人群为适合远景的图集人物，不是逐人高精度模型。人群录音是有归属的通用足球声景，不是拜仁比赛同期声。
