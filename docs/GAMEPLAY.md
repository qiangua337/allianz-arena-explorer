# 亲自上场 · 4.0

打开「比赛日选项」或 [赛前设置](https://allianz-arena-explorer.pages.dev/?place=pitch&night=1&experience=football)，选择对手、难度和镜头，再点击「亲自上场」。默认轻松难度和转播镜头。普通场馆参观、固定拜仁 × 多特的跟队入场继续单独保留。

## 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键，按画面方向移动 | 左下摇杆 |
| 加速 | Shift | 「跑」开关 |
| 短传 | 方向 + J | 摇杆方向 + 传球 |
| 直塞 | 方向 + L | 摇杆方向 + 直塞 |
| 射门 | 按住 K 或 F 蓄力，松手出脚 | 按住射门，松手出脚 |
| 逼抢 / 护球 | 按住 E | 按住逼抢；持球时自动显示护球 |
| 抢断 | 靠近后按空格 | 靠近后点击抢断 |
| 换人 | Q | 换人 |

金色脚环标记受控球员；接近可断的球时变为浅绿色，抢断冷却时变淡。白色三角标记下一位可切换球员，浅色虚线和目标圈说明当前短传选择。没控球时，进攻动作变灰；已经控球时不会误触一个与带球无关的抢断动作。

半自动会在接球和夺回球权后接管持球队员，辅助还会选择较合适的防守球员；手动保留当前人物，按 Q 换人。传球途中队友会迎球；接管后无方向输入会继续迎球，有方向输入即可修正跑位。足球靠近脚前可提前短按传球，形成一脚出球。雷达右端为拜仁的进攻球门。

手机横竖屏分别安排触控区。竖屏镜头更靠近受控球员，横屏显示更宽的传接范围。摇杆、逼抢和蓄力分别维护触点，松手、取消触控、暂停及切走页面都会清理输入。比赛中可随时切换镜头，暂停或终场可更换对手。

比赛会开启全场观众；近处采用有数量上限的坐姿立体人物，远处使用共享图集。点击助威会触发声浪、手臂和旗帜反应，不影响比分、球权或难度。资源与简化范围见 [CROWD-ASSETS.md](CROWD-ASSETS.md)。

回放由用户主动选择，默认半速，可切换原速与重播；回看上次进球，尚未进球时回看最近片段。真实比赛保持冻结，退出或播放结束后点击继续。球门立柱、横梁可以使足球反弹，进球有球网视觉反馈。完整更新见 [REFINEMENT-4.md](REFINEMENT-4.md)。

## 阵容与规则范围

多特、皇马、巴萨、曼城各有 11 名首发和 9 名替补，全部沿用通用人体；首发由本作品选配，没有按现实伤停或某场比赛名单同步。皇马、巴萨与曼城的球衣采用球队配色和字母标记。号码资料及核对日期见 [REFERENCES.md](REFERENCES.md)，资源来源见 [PLAYER-ASSETS.md](PLAYER-ASSETS.md)。

这是 3 分钟本地人机体验赛，支持带球、接应、传射、抢断、扑救、进球、边线球、球门球及角球的简化重开。没有在线玩家、真实赛事实况、越位和完整犯规判罚。门将、碰撞、人物动作及队伍策略仍是简化模拟。

## 验证范围

自动检查覆盖实际球路接收、一脚传球预输入、方向选点、射门力度、持续比赛的扑救、四队阵容、实际人物换装、LED 记分屏、触控取消及暂停释放。浏览器在 390 × 844、844 × 390 和默认桌面视口检查了赛前选队、摇杆、长按、暂停与镜头切换；这是浏览器响应式测试，不是实体手机帧率保证。
