# 5.1：展柜互动与阅读修订

更新日期：2026-10-27。

## 修复的问题

看着凯恩墙面展柜，按 F 却可能打开中央 2013 年冠军杯的故事。原逻辑只比较相机与互动点的距离，未确认看向哪件展品；转身后按键也可能沿用上一帧的选择。

现在使用有限距离的视线射线。个人展柜覆盖实际展板与玻璃柜范围；中央球队奖杯复用可见模型的几何作精确拾取，透明柜体的空白区域不抢占视线。访问者还必须位于展厅内，避免隔着外墙选中物品。按 F 或点击提示时即时重新检查，提示、高亮与介绍共用同一展品 ID。

全场其他物品也要求朝向目标；感应自动门继续自动开启，面向门时可以让门保持开启。相机位置和方向不变时复用选择结果，拾取模型不加入渲染场景，高亮共用一个线框。

## 展陈与辨识

- 个人展柜增加平视姓名 / 年份铭牌、底座姓名 / 奖项 / 类型；两件球衣分别标出姓名号码与配色说明。球队奖杯增加“球队荣誉”提示，区分俱乐部与个人成就。
- 展厅铭牌按实际平面比例生成文字，再放入共享图集。长文字等比缩小，减少拉宽、压扁和近看难辨识。
- 里贝里奖杯由扁平轮廓改为立体中空半身、上扬双臂、颈口与黑色底座；细节依据 [UEFA 获奖公告](https://www.uefa.com/uefachampionsleague/news/0250-0c50fe103b73-0fcc5456ac81-1000--ribery-is-crowned-uefa-best-player-in-europe/) 和 [UEFA 官方奖杯照片](https://editorial.uefa.com/resources/0254-0e99d68cb151-6fb9a729767e-1000/format/wide1/the_uefa_men_s_player_of_the_year_award_trophy.jpeg?imwidth=1000)。该物件标明“银色半身造型奖杯”。
- 金球及纪念足球缩小内部底层球体，避免穿出外层面片，产生灰色三角碎片。
- 手机横屏压缩目录标题、统计和详情头图，内容区域独立滚动，关闭入口保持可用。

奖杯和球衣为原创代表性模型；实物照片只用于参考，不作为模型贴图或项目资产发布。
